자주 묻는 질문

더 많은 간호 정보를 간호 포럼에서 확인하세요.

질문하기

절단점 (Cut-off)

문맹 절단점 <= 20
1~11년 정규 교육 절단점 <= 24
11년 초과 교육 절단점 <= 28

절단점 미만의 점수는 인지 기능 저하 가능성을 시사하며 심층적인 평가가 필요합니다.

관련 평가 도구

  • MoCA 척도

    경도 인지 장애 (MCI) 선별.

  • 글래스고 혼수 척도

    의식 수준 평가 계산기.

  • 주베 (Jouvet) 척도

    혼수 및 의식 상태 척도.

  • 램지 (Ramsay) 척도

    환자의 진정 상태 평가.

  • 카츠 (Katz) 지수

    일상생활수행능력(ADL) 자립도 평가.

  • 자리트 (Zarit) 척도

    가족 부양자 부담 평가.

  • 로튼 (Lawton) 척도

    노인의 도구적 일상생활수행능력(IADL).
