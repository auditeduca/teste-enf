# Templates CKO — esqueletos HTML

Copie o ficheiro do tipo desejado e substitua os placeholders.

| Ficheiro | Tipo | Uso |
|----------|------|-----|
| `home.html` | `home` | Página inicial |
| `institutional.html` | `institutional` | Missão, políticas, termos… |
| `calculator.html` | `calculator` | Escalas e calculadoras |
| `tool.html` | `tool` | Downloads e utilitários |

Contrato: `data/cko-page-templates.json`  
Docs: `docs-internos/CKO-PAGE-TEMPLATES.md`

Validar:

```bash
python tools/validate_page_templates.py --file sua-pagina.html
```
