# Auditoria 360

Cinco direções:

## Direta

Fonte/objeto → conteúdo/projeção.

## Inversa

HTML/questão → claim/assertion → fonte.

## Complementar

Conteúdos distintos que se completam sem serem fundidos.

## Transversal

Relações entre blocos, Regulatory, ferramentas, bibliotecas e provas.

## Diagonal

Caminhos multi-hop, por exemplo:

```text
NORMA → TÓPICO → QUESTÃO → SIMULADO
```

## Evidência gerada neste repositório

- `audit/audit-trail.v1.json`
- `audit/final-360-audit.v1.json`
- `audit/release-manifest.v1.json`
- `reports/ESTADO-ATUAL.md`

Comando: `python3 -m engine.cli audit`.

A geração automática **não** equivale a parecer 360 aprovado. O v0.1 conclui HOLD/FAIL de promoção.
