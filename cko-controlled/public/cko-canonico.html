Achados

  • FND-CANON-TOOL-PUBLISHED-DRIFT — 97 tool JSON files carry status=published. Universal Tool Policy keeps calculators PAUSED and implemented_n=0. Governed status remains HOLD.
  • FND-CANON-LIBRARY-HTML-ONLY — 1332 biblioteca HTML files exist without article atoms. The kind is canonical; the next materialization is JSON atoms + library-article template, not more hand HTML.
  • FND-CANON-NORMS-VERIFY-PENDING — The first normative instrument is atomized and VERIFY_PENDING. C001 and C002 remain open.

Não gerámos 1332 HTML novos. Não promovemos 97 published. Não atribuímos vigência às normas.
