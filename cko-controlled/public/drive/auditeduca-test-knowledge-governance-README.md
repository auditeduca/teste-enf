# AuditEduca Test — Knowledge Governance Working Papers

Pacote repo-ready para inventário de conversas e fontes do ecossistema.

## Conteúdo
- `docs/inventory/conversations/`: master registry, CAAT e IPE.
- `docs/inventory/sources/`: URL registry e fila de aquisição.
- `docs/working-papers/`: documentação de auditoria.
- `schemas/`: contratos declarativos.
- `scripts/`: aquisição controlada e CAAT.
- `.github/workflows/`: execução reprodutível em GitHub Actions.
- `knowledge/`: snapshots brutos, extrações e metadados gerados pelo executor.
- `reports/`: evidência de execução.

## Regra fundamental
Nenhum conteúdo externo é promovido a conhecimento canônico apenas porque foi localizado ou baixado. Promoção exige identidade, integridade, IPE/CARR, validação e assurance.
